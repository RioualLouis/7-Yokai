# 7 Yokai

Projet de réalisation d'un jeu vidéo multijoueur similaire au jeu de cartes 7 Yokais.

## Détails du projet

L'équipe du projet sera composée d'une seule personne, débutante en jeu vidéo multijoueur. Le projet sera développé en Java dans un environnement Maven déjà configuré. Le jeu suivra exactement les règles de jeux du jeu 7 Yokai. Le cahier des charges est le suivant :
* Jeu limité à 4 joueurs (pas de version 3 joueurs)
* Modélisation du jeu (cartes, ...)
* Moteur de jeu (mise en place, tours de jeu, ...)
* Des robots de jeu (3 difficultés correspondant à des stratégies différents, le robot le plus simple jouera aléatoirement)
* La possibilité de jouer à plusieurs joueurs réels (les places vacants seront comblées par des bots)
* Une visualisation de l'état du jeu, adapté à chaque joueur en fonction de l'état de jeu.

## Planning

Le temps imparti est réglé sur le 31 décembre, avec des sprints de 2 semaines, à partir du 26 octobre.
